# wStack 0.12.1 follow-ups

The user picked all six follow-ups that the 0.12.0 reviews left open. Each one is a small fix with its own test and its own commit. The 0.12.0 spec (`docs/superpowers/specs/2026-11-26-phone-first-diagrams-design.md`) stays the authority for the views.

## Constraints

- Python 3.9 standard library. Bash 3.2. Functions under 50 lines, files under 800 lines.
- Write each test first and run it to see it fail.
- Before each commit, run the covering test files (CLAUDE.md). The controller runs the full suite once before the merge.
- `SVG_ARCHITECTURE_SHA256` keeps its value. Every existing test keeps passing.
- Use made-up names in new test inputs.

## Fixes

1. Architecture: if a layer wraps its pills, a straight implements arrow can cross a pill. `lane_pairs` decides by layer depth only. So two pills in neighbor layers get a straight line, even with a wrapped pill row between them. If any pill row lies between the two ends of a pair, give the pair its own lane. Test: a layer that wraps onto two rows, and an implements pair from its first row to the next layer. No implements path passes inside a pill other than its ends.

2. States: a lane under the boxes crosses the arrows that enter its source or leave its target. Example: `q` goes to `a`, `b` and `c`, those three go to `d`, and `d` goes back to `q`. The down leg beside `d` crosses the curves into `d`, and the up leg beside `q` crosses the curves out of `q`. If the source is the last row of its column, the lane leaves through the bottom edge of the source. If the target is the last row of its column, the lane enters through the bottom edge of the target. Otherwise, keep the side legs. Lanes that share one bottom edge are spread `END_GAP` apart and nest, so they do not cross each other. Test: that lifecycle has no crossing, and the existing clean tests still pass.

3. Architecture: implements lanes from different pills cross each other. Example: adapters `a1` and `a2` in one row implement ports `p1` and `p2` two layers down, in the same left-to-right order. Order the lanes so they nest: the lane whose ends are nearest the gap takes the inner band and the inner gap position. When the adapter order and the port order disagree, one crossing is allowed. Test: same order gives no crossing, and reversed order gives at most one crossing per pair.

4. Architecture: with a sibling beside one nested layer and 3 or more lanes, the lowest bands run 2 to 8 px below the nested layer box. Every layer box must hold the bands that run inside it, with the last band at least 4 px above the box bottom. Test with 3, 4 and 6 lanes.

5. Note: `heading_text` does not escape `<` in sequence and state titles, so Obsidian reads `<id>` as an HTML tag. Escape `<` as `&lt;`, the same way `note_text` does for list text. Test: a sequence titled `Get <id>` gives the heading `### Sequence: Get &lt;id&gt;`.

6. `scripts/find-stale-refs.sh`: git quotes a file name with non-ASCII characters by default, so a rename of such a file is missed. Run its git commands with `-c core.quotepath=off`, as `contract-ref-shift.sh` does. Test in `tests/test_find_stale_refs.sh` with a non-ASCII file name.
